# Batch 16 knowledge examples

These payloads demonstrate the knowledge API. Matter-derived work product should normally use the promotion endpoints so provenance is preserved. Promotion does **not** publish content; it creates a draft that still requires sanitization/source review and authorized approval.

Manual entries without a source matter may use `sanitization_status=not_required` at approval, but the reviewer remains responsible for confirming that the content is appropriate for firm-wide reuse.
